# 正确性、性能和失败回退

先约定精度、任务指标容差及性能目标；不要使用任意固定容差代替项目要求。准备相同权重、输入、模式、随机状态和后端配置的独立基线及候选，避免同一模型原地转换污染基线。记录开关状态与实际路径。

- 覆盖典型和边界 shape：batch、通道或空间维为 1，非方形/动态输入，以及真实非连续输入；验证 4D/5D 和无关张量仅在适用的路径转换。核对 shape、stride、格式及数值，关注 NaN/Inf、输出结构和任务指标。对于 alias、缓存、原地操作和自定义算子检验其约定。
- 训练时用相同初始参数、优化器、AMP 和随机状态对比 forward、loss、输入/参数梯度、一次及多个更新、buffer 和保存恢复；按项目容差评估随机和非确定性影响。推理覆盖实际 eval 和缓存生命周期。
- 核对布局真正落到每个卷积和自定义算子的输入上，而不仅是入口：在边界处记录 `stride()` 与 `is_contiguous(memory_format=...)`，并确认融合或自定义算子没有回退到普通路径。配置文件里出现开关或 ROCm 变量，不等于路径命中。名为 `channels_last` 的参数可能只是轴排列（如 `permute` 后的 NHWC），不要和 memory format 混淆。
- 在实际使用条件下分开检查 eager 和 compile 的功能、guards/重编译、首轮和稳态；DDP/FSDP 时覆盖各 rank 与同步/状态。确认开关关闭后的原始路径以及失败时的显式回退；模拟不支持/抛错场景时避免隐藏真实错误。
- 隔离变量：布局开关对照，必要时再做 compile 开关及 ROCm 环境变量的独立消融。使用代表性输入和工作负载，预热足够且记录次数、同步 GPU（ROCm 上 PyTorch 通常仍使用 `torch.cuda.synchronize()`），多次测量中位数和离散范围；标明计时窗口、样本、batch、吞吐或延迟单位，记录峰值显存。分别测包含输入转换的端到端，以及局部子图；通过 profiler 观察复制和布局传播。报告初始化、编译、搜索和稳态，避免把一次冷启动混入稳态。
- 汇报版本、硬件、输入、命令、开关、容差、结果、测量分布、未验证项。若没有目标环境或实际收益不满足阈值，记录未验证/回退，不能把示例或源码配置当成实验结果。
